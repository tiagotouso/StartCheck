cli-installer (CLI Interativo & NPX)

Interface de linha de comando baseada em @clack/prompts para inicialização e controle total de fluxo.

Visão Geral da Especificação

O cli-installer provê uma experiência de terminal imediata via npx startcheck install. Responsável pela inicialização do ambiente, criação da pasta isolada da startup, e despacho interativo para criação e revisão.

Requisitos Funcionais Principais:

  • RF-01: Execução direta via comando NPX sem clone manual.
  • RF-02: Criação da pasta dedicada da startup com startup.config.json.
  • RF-03: Menus para criação: um por um, por grupo e todos de uma vez.
  • RF-04: Menus para revisão: um por um, por grupo e todos com inserção de justificativas.
  • RF-05: Despacho automatizado do serviço de exportação multiformato.

Exemplo de Invocação

# Instalação interativa
npx startcheck install

# Execução no diretório corrente
npx startcheck
