# Mapeamento de Riscos da Ideia

> Documento para mapear os maiores riscos que podem inviabilizar a startup e definir formas rápidas de testá-los antes de gastar tempo e dinheiro.

---

## 1. Quadro de Avaliação dos Riscos da Ideia

| Categoria do Risco | Qual é o Risco Específico? | Gravidade (Alta / Média / Baixa) | Probabilidade (Alta / Média / Baixa) | Como Testar ou Mitigar Rápido? |
| :--- | :--- | :---: | :---: | :--- |
| **Risco de Mercado (Interesse)** | O cliente não ter interesse real ou a dor não ser grande o bastante para ele buscar uma solução. | [Alta / Média / Baixa] | [Alta / Média / Baixa] | [Entrevistas de validação ou teste de fumaça com página de cadastro] |
| **Risco Financeiro (Preço)** | O cliente achar a solução útil, mas não aceitar pagar o valor necessário para o negócio se sustentar. | [Alta / Média / Baixa] | [Alta / Média / Baixa] | [Apresentar proposta de pré-venda ou simulação de preços em entrevistas] |
| **Risco de Execução (Técnico)** | A equipe não conseguir construir a tecnologia ou o processo de entrega ser complexo demais. | [Alta / Média / Baixa] | [Alta / Média / Baixa] | [Criar um protótipo manual (Concierge) antes de programar o sistema] |
| **Risco Regulatório / Parceiros** | Depender de licenças, leis rígidas, APIs de terceiros ou parceiros que podem travar o negócio. | [Alta / Média / Baixa] | [Alta / Média / Baixa] | [Consultar regras do setor ou validar termos de uso com os parceiros-chave] |
