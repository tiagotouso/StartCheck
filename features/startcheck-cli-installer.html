startcheck-cli-installer

Pacote de linha de comando Node.js distribuível via NPX ou GitHub para automação da instalação do ecossistema de agentes.

Score 94.0 / 100 RFC Pragmático Status: Implementado

Requisitos Funcionais Principais

ID Requisito Prioridade Critério de Aceite
RF-01 Fornecer ponto de entrada executável via npx startcheck install. Must Comando executa e retorna exit code 0.
RF-02 Copiar integralmente os 25 agentes e templates para .agents/agents/. Must Verificação de existência de todos os arquivos.
RF-03 Gerar e sincronizar regras em AGENTS.md, CLAUDE.md e GEMINI.md. Must Arquivos configurados com a chamada /startcheck.
RF-04 Operação não-destrutiva com proteção contra sobrescrita indevida. Must Falha segura e preservação de arquivos existentes.
